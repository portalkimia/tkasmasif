Konfigurasi koneksi API Google Apps Script untuk realtime sync

Tempelkan URL Web App dari deployment Google Apps Script Anda (berakhiran /exec).

💡 Cara Mendapatkan URL Web App Google Apps Script:

  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Buka menu Ekstensi (Extensions) > Apps Script.
  3. Salin seluruh kode dari file gas/Code.gs di repo ini, lalu tempel ke editor Apps Script.
  4. Jalankan fungsi setupSheet sekali untuk mengisi data awal ruang & warna.
  5. Klik Deploy (Terapkan) > New deployment (Penerapan baru).
  6. Pilih tipe Web app, atur Who has access ke Anyone (Siapa saja).
  7. Salin URL Web App dan tempelkan di kotak isian di atas!
